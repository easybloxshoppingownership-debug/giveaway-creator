# giveaway-creator

A Discord bot for creating and managing giveaways.

## Setup

1. Set the `DISCORD_TOKEN` environment variable to your bot's token.
2. Run `npm install`.
3. Run `npm start`.

## Commands

- `!ping` — Replies with "Pong!" to confirm the bot is responsive.
- `!giveaway <title>` — Creates a new giveaway.
- `!giveaways` — Lists all active giveaways.
